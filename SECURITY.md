# Security policy

RepoGuard is an early, best-effort security tool, not a substitute for a professional audit or other security controls. The latest release is the intended supported version; no response or remediation timeline is guaranteed.

## Reporting a vulnerability in RepoGuard

Please **do not** publish working exploits, actual secrets, private repository contents or sensitive reports in a public issue. Use GitHub's private vulnerability reporting for this repository if it is enabled. Otherwise, contact the repository owner through a private channel before sharing sensitive details. A minimal reproduction with synthetic data is preferred.

If you find an exposed credential in your own project, revoke or rotate it immediately, assess access, and remove it from files and history. RepoGuard cannot revoke credentials for you.
